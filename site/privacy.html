音赴光年隐私政策

生效日期：2026年10月26日

音赴光年由个人开发者「追光狗」发布。本政策说明这款播放器在你的设备上保存什么，以及联网时会把什么发给谁。

音赴光年没有自己的账号系统，不出售个人信息，也不投放广告。

保存在本机的内容

下列内容只写在你的设备上，由你自己的播放器使用：

  • 歌单、播放历史、播放进度和播放方式
  • 音质、主题、窗口大小等设置
  • 缓存的音频、封面和歌词

你可以在应用里清空播放历史，删除缓存，或删除歌单。

登录

登录是可选的。不登录也可以搜索、播放、查看歌词、建立歌单和缓存。

扫码登录成功后，登录 Cookie 保存在操作系统提供的安全存储里，包括会话标识和用户标识。这些 Cookie 只随后续的搜索、播放和账号相关请求发给哔哩哔哩的服务器（passport.bilibili.com 与 api.bilibili.com）。开发者没有接收这些 Cookie 的服务器。

退出登录会从本机删除这些 Cookie。

应用还会在本机生成一个设备标识，并把它放进发给哔哩哔哩的请求里，用来完成接口访问。退出登录不会删除这个设备标识。

联网时发出的内容

  • 搜索词、播放请求和字幕请求发给哔哩哔哩。
  • 匹配歌词或专辑资料时，歌名和歌手名可能发给这些公开接口：LRCLIB（lrclib.net）、网易云音乐（music.163.com）、QQ 音乐（c.y.qq.com）、Apple（itunes.apple.com）。
  • 从网站或 GitHub 直接安装的版本，会向 GitHub（api.github.com）查询是否有新版本。这个请求不附带你的登录 Cookie。
  • 从 Microsoft Store 安装的版本由商店更新，不向 GitHub 查询。

应用不接入统计服务，也不把崩溃报告发给开发者。运行日志留在本机，其中不记录登录 Cookie。

儿童

音赴光年不是为不满 14 周岁的儿童制作的。开发者不会故意收集儿童的个人信息。

政策变更

本政策如有修改，会更新本页并改写上面的生效日期。
