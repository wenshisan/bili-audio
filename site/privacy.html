音赴光年隐私政策

生效日期：2026年10月29日
更新日期：2026年10月29日

本隐私政策单独成文，只说明「音赴光年」这款播放器如何处理信息，不是任何用户协议的一个章节。应用里的《隐私政策》打开的就是这一页，和提交到应用商店的地址是同一份：https://wenshisan.github.io/bili-audio/privacy.html。

运营者

音赴光年由个人开发者「追光狗」开发并运营。追光狗是本应用的研发方和运营方，也是本政策下的个人信息处理者（下称「我们」）。

联系邮箱：wenshisan@live.cn。我们会在收到邮件并核实后的 15 个工作日内回复。

音赴光年没有自己的账号系统，不出售个人信息，也不投放广告。

我们处理的信息

下面按实际功能说明处理的信息、目的和方式。没有列出的信息，我们不收集。

  • 搜索、播放和歌词：你输入的搜索词，以及当前曲目的歌名、歌手名，会在查询时通过网络发出。目的是找到音频、歌词和专辑资料。
  • 登录（可选）：登录成功后，登录 Cookie（会话标识和用户标识）保存在操作系统提供的安全存储里。不登录也可以搜索、播放、查看歌词、建立歌单和缓存。登录 Cookie 属于个人敏感信息，只为让哔哩哔哩识别这次登录，从而使用更高音质和账号相关接口。
  • 设备标识：应用会在本机生成或取得一对设备标识（buvid），并放进发给哔哩哔哩的请求里，用来完成接口访问。它不是手机的 IMEI、OAID 或 MAC 地址。设备标识属于可用于识别设备的个人信息。
  • 只保存在本机、不上传给开发者的内容：歌单、播放历史、播放进度、播放方式、搜索历史、音质、主题、窗口大小，以及缓存的音频、封面和歌词。

音赴光年不读取 IMEI、OAID、MAC 地址、位置、通讯录、短信、通话记录、相册或已安装应用列表。没有接入广告、统计或消息推送 SDK。

系统权限只在对应功能里使用：网络用于搜索、播放和歌词；通知用于显示正在播放的曲目，可在系统设置里关闭；前台服务用于退到后台后继续播放。从网站直接安装的版本在应用内更新时，还会使用安装应用权限。从应用宝或其他应用商店安装的版本由商店更新，不在应用内下载安装包。

登录与注销

登录页会先请你阅读本政策。未勾选「我已阅读并同意《隐私政策》」时，不能完成登录。勾选不是默认选中的。

音赴光年没有可供注册的独立账号。登录用的是哔哩哔哩账号，本应用只在你的设备上保存登录凭证。解除这层关联，按下面的步骤退出登录：

  1. 打开音赴光年，点底部「我的」。
  2. 在账号一栏点「退出登录」。
  3. 在确认框里点「确定」。

完成后，本机保存的登录 Cookie 会被删除。开发者没有接收这些 Cookie 的服务器，所以没有另一份服务器账号需要另行注销。退出登录不会删除设备标识。

哔哩哔哩账号本身要在哔哩哔哩的客户端或网页按其自己的流程注销。音赴光年代为注销不了那个账号。

本机其他数据可以自己删掉：

  • 搜索历史：在「发现」页搜索框下的「搜索历史」里点「清空」。
  • 播放历史：点底部「歌单」，再点「播放历史」，然后点「清空历史」。
  • 缓存：点底部「我的」，再点「管理缓存」后删除。
  • 歌单：在「歌单」里删除对应歌单。
  • 设备标识和剩余的本机数据：卸载音赴光年，或在系统设置里清除本应用的数据。

如果这些步骤不够，或你需要我们协助确认是否还持有与你有关的信息，请发送邮件到 wenshisan@live.cn，标题写明「注销」或「删除个人信息」。我们将在 15 个工作日内完成核查。目前开发者没有保存用户账号的服务器；若以后持有相关信息，会在上述期限内删除或匿名化，法律法规要求保留的除外。

发给其他服务的信息

播放器在对应功能发生时，直接访问下面的服务。它们不是嵌在安装包里的第三方 SDK。登录 Cookie 只发给哔哩哔哩。

  • 哔哩哔哩（passport.bilibili.com、api.bilibili.com）。目的：搜索、播放、字幕和登录。信息：搜索词、播放和字幕请求；登录后还有登录 Cookie 和设备标识。
  • 网易云音乐（music.163.com）。目的：匹配歌词、专辑资料，或读取公开的年代歌单。信息：歌名和歌手名，或公开歌单请求。不含登录 Cookie。
  • QQ 音乐（c.y.qq.com）、酷狗音乐（mobileservice.kugou.com、lyrics.kugou.com）、酷我音乐（search.kuwo.cn、m.kuwo.cn）、LRCLIB（lrclib.net）。目的：匹配歌词。信息：歌名和歌手名。不含登录 Cookie。
  • Apple（itunes.apple.com）。目的：匹配专辑封面和发行年份。信息：歌名和歌手名。不含登录 Cookie。
  • GitHub（api.github.com）。目的：从网站或 GitHub 直接安装的版本查询是否有新版本。这个请求不附带登录 Cookie。从应用商店安装的版本由商店更新，不向 GitHub 查询。

LRCLIB、Apple 和 GitHub 的服务器不在中国境内。发往这三处的内容只有歌名、歌手名或版本检查，没有登录 Cookie。歌词和专辑查询发生在播放、需要匹配这些资料的时候。

我们不向这些服务出售个人信息。除上面列出的用途外，不把你的信息提供给其他接收方。法律法规另有要求时，会按法律提供。

个性化推荐

音赴光年不根据搜索记录、播放历史、设备标识或其他个人信息做个性化推荐，也不投放广告或定向推送。发现页的热门和排行是公开榜单，按热度、分类或年代排列，不读取你的个人记录来挑选内容。

因此应用里没有「个性化推荐」开关。搜索历史和播放历史只留在本机供你自己回看，可以按上一节的步骤清空。

保存期限

本机上的歌单、历史、缓存、设置和设备标识，一直留到你按上面的步骤删除、清除应用数据或卸载。登录 Cookie 留到你退出登录。开发者没有服务器副本。

发给哔哩哔哩和其他服务的内容，由那些服务按其自己的规则保存。运行日志留在本机，其中不记录登录 Cookie。应用不把崩溃报告发给开发者。

你的权利

你可以查阅、更正和删除上述信息，也可以撤回同意：

  • 查阅：登录状态在「我的」的账号一栏；歌单、播放历史和搜索历史在应用里直接可见。
  • 更正：歌单、音质、主题等设置可以在应用里修改。哔哩哔哩昵称和头像在哔哩哔哩侧修改。
  • 删除和撤回同意：按「登录与注销」里的步骤退出登录、清空历史或卸载。退出登录就是撤回把登录 Cookie 发给哔哩哔哩的同意。

要我们协助办理时，写信到 wenshisan@live.cn。我们会在 15 个工作日内回复。为确认请求来自你本人，邮件里请说明你使用的设备和应用内能看到的账号昵称（如果曾登录）。

儿童

音赴光年不是为不满 14 周岁的儿童制作的。不满 14 周岁的儿童使用前，应让父母或其他监护人阅读本政策和单独的《儿童隐私政策》。儿童隐私政策的地址是 https://wenshisan.github.io/bili-audio/children.html。

我们不会故意收集儿童的个人信息。监护人如果认为孩子向我们提供了个人信息，可以按儿童隐私政策里的方式联系我们删除。

政策变更

本政策如有修改，会更新本页，并改写上面的生效日期和更新日期。应用内《隐私政策》打开的仍是这一页，因此你看到的文本和本页保持一致。
