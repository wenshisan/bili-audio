能做什么

  • 搜索音乐内容，过滤超过 15 分钟的视频。
  • 按分 P 连续播放，标题会整理成歌名和歌手。
  • 匹配歌词，后台播放，并记住本地歌单和缓存。

下载

正在读取最新安装包…

Windows 64 位安装程序。未签名，SmartScreen 可能提示未知发布者。 macOS Apple 芯片磁盘映像。未公证，需在隐私与安全性中允许。 Linux x64 的 deb。可用 sudo dpkg -i 安装。 Android 直接安装的 APK。需要允许安装未知应用。 iOS 用 iPhone 自带的 Safari 打开本页。系统按描述文件安装，完成后到「设置 → 通用 → VPN 与设备管理」里信任。

安装包由 GitHub Actions 在推送到 main 后生成；第一次构建完成前，上面的链接会暂时打不开。iOS 描述文件安装还需要仓库里配置好的 Apple 签名，没有签名时这个按钮不可用。

应用内“检查更新”只提示带 v 版本号的正式发布。上面的按钮在还没有正式版时，会下载名为 continuous 的预发布包。
